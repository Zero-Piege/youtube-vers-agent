# youtube-vers-agent

Навык Claude Code, который преобразует учебные пособия YouTube в навыки Claude Code через двойную проверку источников (локальный Claude + Gemini) и перекрестную проверку спецификаций.

## Описание

Этот навык преобразует содержание учебных пособий YouTube в структурированные навыки Claude Code посредством:
1. Извлечения ключевых концепций и процедур из транскриптов видео
2. Проверки информации через двойную валидацию источников (видео + документация)
3. Создания правильно оформленных файлов SKILL.md согласно соглашениям Claude Code
4. Обеспечения точности и полноты через перекрестную проверку ссылок

## Когда использовать

Используйте этот навык, когда вы хотите:
- Преобразовать образовательный контент YouTube в повторно используемые навыки Claude Code
- Создавать навыки на основе обучающих видео о инструментах разработки, фреймворках или методологиях
- Обеспечивать точность навыков через проверку с официальной документацией
- Строить библиотеку проверенных навыков из видеообучающих ресурсов

## Workflow навыка

### 1. Фаза анализа видео
- Обработайте видео YouTube с использованием навыка watch для извлечения транскрипта и ключевых кадров
- Определите основные темы, процедуры и примеры кода, представленные в видео
- Сформулируйте учебные цели и результаты

### 2. Двойная проверка источников
- Для каждого ключевого концепта/процедуры обратитесь к официальной документации с использованием навыков context7-mcp или find-docs
- Сверяйте содержание видео с авторитетными источниками
- Отмечайте любые расхождения или различия в версиях
- Проверяйте, работают ли примеры кода как демонстрировалось

### 3. Создание навыка
- Сгенерируйте правильно оформленный файл SKILL.md согласно соглашениям Claude Code
- Включите четкое описание, рекомендации по использованию и пошаговый рабочий процесс
- Ссылайтесь как на источник видео, так и на источники документации, использованные для проверки
- Добавьте рекомендации по инструментам, основанные на проверенных процедурах

### 4. Обеспечение качества
- Протестируйте примеры кода или упомянутые процедуры
- Проверьте, соответствует ли навык стандартам форматирования навыков Claude Code
- Убедитесь, что навык предоставляет выполнимые и проверяемые рекомендации

## Выход

Создает полный файл SKILL.md в соответствующем каталоге .claude/skills/, который:
- Четко определяет цель и применимость навыка
- Предоставляет конкретные рекомендации по использованию
- Описывает проверяемый рабочий процесс
- Ссылается на источники, использованные для двойной проверки источников
- Следует соглашениям навыков Claude Code

## Требуемые инструменты

- watch: Для обработки содержимого видео YouTube
- context7-mcp или find-docs: Для двойной проверки источников относительно официальной документации
- Bash: Для операций с файлами и создания навыков

## Установка

1. Клонируйте этот репозиторий:
   ```bash
   git clone https://github.com/Zero-Piege/youtube-vers-agent
   ```

2. Скопируйте навык в ваш каталог навыков Claude Code:
   ```bash
   cp -r .claude/skills/youtube-vers-agent ~/.claude/skills/
   ```

3. Перезагрузите плагины:
   ```bash
   /reload-plugins
   ```

## Использование

После установки вы можете использовать навык, предоставив URL YouTube и указав, что вы хотите создать:

```
/youtube-vers-agent [URL YouTube] [что извлечь] [что создать]
```

Пример:
```
/youtube-vers-agent https://youtu.be/zke3bTtvmLo Весь проект Навык Claude Code
```

## Пример использования

Преобразуйте обучающее видео YouTube о создании компонентов React в навык Claude Code:
1. Используйте навык watch для извлечения транскрипта видео и ключевых моментов
2. Используйте context7-mcp для проверки моделей создания компонентов React относительно официальной документации React
3. Создайте SKILL.md с проверенными процедурами создания компонентов React в Claude Code
4. Включите ссылки как на обучающее видео YouTube, так и на используемую документацию React

## Стандарты проверки

Все созданные навыки должны:
- Ссылаться на как минимум два независимых источника (видео + документация)
- Включать конкретные, выполнимые шаги
- Предоставлять четкие рекомендации по использованию
- Следовать установленному формату навыков Claude Code
- Содержать проверяемые процедуры, которые можно протестировать
